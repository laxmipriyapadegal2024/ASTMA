# Methodology

This project is designed to separate three dimensions of political content analysis:

## 1. Engagement bait
This dimension looks for explicit direct requests such as likes, comments, shares, tags, or reposts. It is not the same as opinionated political speech.

## 2. Manipulation techniques
This dimension identifies a set of rhetorical indicators such as urgency, fear appeal, false dilemma, social pressure, identity-based pressure, or unsupported conspiracy framing. These are observable communication patterns, not proof of intent.

## 3. Factual evidence status
This dimension looks at whether a claim has available support, contradiction, or insufficient evidence. It does not assume political disagreement is misinformation.

The output remains intentionally separated so researchers can review each layer independently before drawing conclusions.
